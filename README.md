# FitTrack

Projeto acadêmico demonstrativo de Desenvolvimento de Interfaces.

## Estrutura
- `index.html`: estrutura e conteúdo informativo sobre exercícios, alimentação, sono, recuperação e bem-estar.
- `style.css`: identidade visual, layout responsivo, temas e estilos.
- `script.js`: interações, filtros de conteúdo, carrossel de imagens, acessibilidade e validações.

## Como executar
1. Extraia os arquivos.
2. Abra `index.html` em um navegador moderno.
3. Para uma experiência melhor durante o desenvolvimento, use a extensão Live Server do VS Code (opcional).

## Observações
- O login é apenas demonstrativo: não existe autenticação nem armazenamento de usuários.
- O formulário valida os dados no navegador, mas não envia mensagens a um servidor.
- As fotografias são carregadas do Unsplash e exigem conexão com a internet.
- O Google Fonts também depende de conexão; fontes alternativas serão usadas se não carregar.
- O conteúdo é educativo e não substitui orientação individual de profissionais de saúde.

## Tecnologias
HTML5, CSS3 e JavaScript puro.

## Proposta do site
O FitTrack é um portal exclusivamente informativo. Não oferece acompanhamento individual, prescrição de treinos, planos alimentares ou cadastro real de usuários. O botão de login e os formulários são demonstrações de interface para fins acadêmicos.
